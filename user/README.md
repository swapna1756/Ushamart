# UshaMart User

User Application for UshaMart grocery delivery platform.
Fetches all data from the Admin Backend API — no database, no server.

## Structure
```
user/
└── frontend/    React User Application  (port 8080)
```

## Quick Start
```bash
cd frontend
npm install
npm run dev     # http://localhost:8080
```

## Requirements
- Admin Backend must be running on http://localhost:5000

## Tech Stack
- React + Vite + Tailwind CSS
- REST API integration only
- No backend / no database
